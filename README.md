# 🍽️ RestoPulse — Restaurant Management & POS

**RestoPulse** is a cloud-based **Multi-Tenant Restaurant Management & POS System** built with React and Firebase.

It provides restaurants with a complete platform for **POS billing, kitchen management, tables, reservations, inventory, analytics, invoices, and digital menus**.

### 🌐 Live Demo

🚀 **https://restaurantspos.vercel.app**

---

## ✨ Features

* 👑 **Super Admin** — Manage multiple restaurants and admins
* ⚡ **POS** — Fast order entry, KOT, discounts & billing
* 👨‍🍳 **KDS** — Real-time kitchen order management
* 🪑 **Table Management** — Live table availability & orders
* 📅 **Reservations** — Customer table booking management
* 💳 **Billing & Invoices** — Cash, Card & UPI payments
* 📦 **Inventory** — Stock tracking & low-stock alerts
* 📊 **Analytics** — Revenue, AOV & top-selling dishes
* 📖 **Digital Menu** — Public restaurant menu
* 🖼️ **ImgBB Integration** — Cloud image hosting
* 🔐 **Multi-Tenant Security** — Restaurant-level data isolation

---

## 🛠️ Tech Stack

* **Frontend:** React 18, Vite, Tailwind CSS
* **Database:** Firebase Firestore
* **Authentication:** Firebase Auth
* **Routing:** React Router
* **Icons:** Lucide React
* **Image Hosting:** ImgBB API
* **Deployment:** Vercel

---

## 🏗️ Architecture

```text
React + Vite
     │
     ├── Firebase Authentication
     ├── Cloud Firestore
     ├── Firestore Security Rules
     ├── ImgBB Cloud Media
     └── Vercel
```
